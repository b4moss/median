# メディア加工パイプライン

- **状態**: 仕様詳細
- **マイルストーン**: `v0.2.0`
- **関連**: [core-api.md](./core-api.md)

## 範囲（v0.2.0）

- 画像の圧縮（する / しない）
- 本体のリサイズ制約（長辺 / 短辺 / 絶対指定）
- サムネイル生成（複数サイズ、個別圧縮率、cover / contain / squeeze）

**含めない**: SVG サニタイズ、PDF 先頭ページサムネ（→ `plans/unscheduled/`）

## 画像フォーマット（初回）

- JPEG / PNG / WebP / GIF
- アニメ GIF・APNG も対象

## 圧縮とオリジナル

- 圧縮とサムネイルは**独立したオプション**
- 圧縮 ON 時のデフォルトは、アップロード先にオリジナルを保存しない
  - 「オリジナル保存」フラグで上書き可能
- 画像**本体**に長辺（または短辺・絶対サイズ）制約を付けた場合は、オリジナル保存を**明示的に否定した**とみなす
  - 制約適用後のバイナリが保存対象（原寸ファイルは書かない）

## 推奨処理順

1. 入力解釈（multipart / base64 / bytes / stream）
2. MIME 検査・サイズ上限
3. SVG サニタイズ（対象時・後続版）
4. 本体のリサイズ制約（指定時）
5. 圧縮（指定時）
6. サムネイル生成（指定時）
7. ストレージ保存 +（DB 使用時）メタデータ記録

## サムネイル（DB 使用時）

- 派生は同一テーブルの子行（`original_id` で親を参照）
- 詳細カラムは [db-media.md](./db-media.md) / [er.dbml](../../er.dbml)
