# v0.1.0 — Go スキャフォールド

- **状態**: 出荷済
- **マイルストーン**: `v0.1.0`
- **関連**: [roadmap](../../roadmap.md)

## 目的

`packages/go` 配下に、後続実装（`v0.2.0`）が載るディレクトリ骨格だけを用意する。

## 範囲

- ディレクトリ作成
- 各ディレクトリに `.gitkeep` のみ（実装ソース・テスト・go.mod は置かない）

## やらぬこと

- 実行可能なコード、テスト、CI ジョブ本体
- マイグレーション SQL の中身（`migrations/` の配置方針は `v0.2.0` で扱う）

## 受け入れ

- `packages/go` 配下の合意したサブディレクトリが存在し、中身は `.gitkeep` のみ
- ライブラリとして import / 実行できる状態にはなっていない
